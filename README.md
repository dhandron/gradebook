Gradebook utility for use with Canvas, WeBWorK, and course roster files

1. Utility will read .csv files downloaded from my 
- Registrar, 
- Canvas, and 
- WeBWorK

2. Compute: 
- cumulative averages for students, 
- statistical data for assignments, 
- performance metrics for student advising

3. Output: 
- course roster in WeBWorK classlist format for upload to WeBWorK 
- WeBWorK grades in Canvas upload format
- Course grades file for upload to registrar
